# Luna-Sklad — Складской учёт для ресторана

Система управления складом и ERP для ресторана. Доступна через веб-браузер и Telegram-бот.

---

## 🌐 Веб-интерфейс

### Вход в систему
1. Откройте сайт M-Sklad
2. Нажмите «Войти» и введите Email
3. Вы окажетесь на главной панели (Дашборд)

## 📦 Основные разделы

### Позиции склада (`/items`)
- Просматривайте все товары с текущим остатком и стоимостью
- Добавляйте новые позиции: название, категория, единица измерения, цена, минимальный остаток
- Загружайте фото товара
- Красный индикатор — остаток ниже минимума (нужно закупить)

### Поступления (`/receipts`)
- Оформляйте приход товаров: выбирайте позицию, вводите количество, цену, поставщика
- Прикрепляйте до нескольких фото накладных
- Остаток на складе обновляется автоматически

### Списания (`/write-offs`)
- Оформляйте списание: выбирайте позицию, количество, причину, ответственного сотрудника
- Доступные причины: бой, порча, хищение, естественная убыль, списание по акту, иное
- При каждом списании Завхоз получает уведомление в Telegram

### Инвентаризация (`/inventory-audits`)
- Фиксируйте фактические остатки для сверки с учётными данными

### Аренда (`/rentals`)
- Оформляйте временную выдачу оборудования: кому, сколько, до какого числа
- Просроченные аренды автоматически подсвечиваются и бот уведомляет Завхоза

### Отчёты (`/reports`) — только для Завхоза
- Выберите период и категорию (или «Общий» по всему складу)
- Скачайте Excel-файл со сводкой: остатки, поступления, списания
- Используйте «Печать» для PDF

## 🤖 Telegram-бот

### Первый вход
1. Найдите бота в Telegram и нажмите `/start`
2. Введите свой рабочий Email (тот же, что в системе M-Sklad)
3. Привязка сохраняется навсегда — после перезапуска бота Email вводить снова не нужно

### Главное меню

```
📊 Аналитика и Отчёты   📦 Управление Складом
⚙️ Настройки и Доступы  👤 Профиль
```

### 📊 Аналитика и Отчёты
- Нажмите кнопку — появятся категории товаров + «Общий отчёт»
- Выберите категорию → выберите формат: **Excel** или **Текстовый**
- Отчёт формируется за текущий месяц

### 📦 Управление Складом

| Кнопка                  | Действие                                               |
|-------------------------|--------------------------------------------------------|
| 📦 Все остатки          | Список всех позиций с индикатором 🟢🟡🔴              |
| 🔍 Поиск товара         | Введите часть названия — бот найдёт совпадения         |
| ⚠️ Критический остаток  | Список позиций, где остаток ниже минимума              |
| 📸 Новое списание       | Оформить списание прямо из бота (только Завхоз/Управляющий) |

### Инлайн-действия при просмотре товара
После поиска или выбора товара под карточкой появляются кнопки:
- `📉 Списать [Товар]` — начать оформление списания для этой позиции
- `📥 Пополнить [Товар]` — зафиксировать пополнение (только Завхоз)

### ⚙️ Настройки (только Завхоз)
- Показывает всех пользователей системы и статус привязки Telegram
- `/logout` — отвязать свой Telegram от аккаунта (для смены аккаунта)
- `/myid` — узнать свой Telegram Chat ID

### Автоматические уведомления (Завхозу)
| Событие                      | Сообщение                                      |
|------------------------------|------------------------------------------------|
| Списание создано              | 📝 Кто, что, сколько, причина                 |
| Остаток упал ниже минимума   | ⚠️ Название, остаток, минимум                 |
| Аренда просрочена            | 🔴 Арендатор, товар, дата                     |

## 👤 Добавление сотрудников

1. Откройте **Настройки** → **Пользователи**
2. Введите Email сотрудника и выберите его роль
3. Сотрудник должен зайти на сайт M-Sklad под этим Email и завершить регистрацию
4. После этого он может авторизоваться в Telegram-боте, отправив `/start` и введя свой Email

## 🔐 Переменные окружения (для разработчиков)

| Переменная               | Описание                              |
|--------------------------|---------------------------------------|
| `TELEGRAM_BOT_TOKEN`     | Токен Telegram-бота (BotFather)       |
| `CLERK_SECRET_KEY`       | Секретный ключ Clerk (аутентификация) |
| `CLERK_PUBLISHABLE_KEY`  | Публичный ключ Clerk                  |
| `DATABASE_URL`           | Строка подключения к PostgreSQL       |
| `DEFAULT_OBJECT_STORAGE_BUCKET_ID` | ID бакета для фото         |

База данных управляется Replit PostgreSQL и сохраняется при любых перезапусках.

---

## 🚀 Деплой

Приложение деплоится через кнопку **Publish** в Replit. После деплоя:
1. Telegram-бот автоматически регистрирует вебхук на правильный домен (`.replit.app`) при запуске — никаких дополнительных настроек не нужно
2. Убедитесь, что все секреты (`TELEGRAM_BOT_TOKEN`, `CLERK_SECRET_KEY` и др.) добавлены в production-окружение
